# DayReader

An Android reading app and home-screen reader widget by Elijah Wright.

## Download

[Download DayReader 3.2](https://github.com/sundaespecial/dayreader/releases/latest)

Open the release and download `Dayreader-3.2.apk`. Requires Android 8.0 or newer. Open the APK on your Android device and allow installation from the app used to open it when prompted.

DayReader provides a home-screen reader for public RSS, Atom, and publication feeds. The Android package is `com.folio.reader`, retaining the identity used by earlier FOLIO builds.

This release is the exact APK retrieved from the author's installed phone app. The APK is distributed unchanged, preserving its existing signing identity. This repository contains the downloadable Android build and release documentation; application source code is not included.
